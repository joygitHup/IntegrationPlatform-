## 关键决策

**0. 客户版与技术版分开写，不是同一份稿子删掉术语。**

两者组织逻辑完全不同：集成商版按「动作顺序」走（开户 → 拉规范 → 登记 → 映射 → 触发），客户版按「痛点 → 价值 → 顾虑 → 边界」走。客户版的四条价值主张全部翻译成业务语言：

| 技术表述 | 客户版说法 |
|---|---|
| 应用集成 / 单点登录 | 一套账号，走遍所有系统 |
| 数据集成 / ETL 与字段映射 | 数据自己流动，不用人搬 |
| 消息集成 | 系统之间能"对话" |
| 身份与组织同步 | 人员变动，账号跟着走 |

客户版专设一章「你最该问的几个问题」，回答的是业务方真实顾虑：会不会动我的现有系统、密码安不安全、上线要多久、谁来维护、成本可不可控、出问题能不能查。答案全部对应到真实机制（加密存储、测试生产隔离、配额上限、执行记录与快照、越权返回"不存在"），但只说结论不解释原理。

**0b. 客户版把"它不做的事"写在了第 6 章，位置很靠前。**

面向客户的材料最容易犯的错是把边界藏在最后。这里主动列出 5 项做不到的事（不做报表分析、不做对外客户界面、不是毫秒级实时、不管主数据标准、账单与状态页在路上）。**在客户面前划清边界，比多讲一个卖点更能建立信任**，也能避免后期因为"你们当时没说"产生的摩擦。

**1. 读者锁定为集成商 / 合作伙伴，全文围绕"我怎么最快接进来"组织。**
这不是一份功能清单，而是一条接入路径。所有章节按集成商的实际动作排序：自助开户 → 拉规范 → 登记数据源 → 探测预览 → 建任务触发，最后才讲治理与边界。

**2. 文风兜底方案。** 工作空间内没有历史公众号文章，无法提炼 14 维文风 DNA，因此采用面向开发者的 B2B 技术文风：平视、克制、具体，技术细节交给表格和代码块，不使用"赋能""闭环""一站式""颠覆"这类词。**如果你有历史推文，把它给我，我可以按你的真实风格重写一版。**

**3. 主动写清楚能力边界。** 目标读者是开发者，"只夸不认"会直接损伤可信度。文中明确列出 7 项未落地能力（CDC / binlog、Temporal、K8s、Parquet 批传、白标嵌入、SLA 状态页、按行计费），并单独说明钉钉/企微/AD/LDAP/飞书这 5 个连接器**只能作抽取源、不能作写入目标**。

**4. 标题推荐"不碰客户的数据库密码，也能把数据同步做完"。**
命中集成商最真实的摩擦点（不想让客户生产库密码散落在项目代码里），且正文有硬机制支撑（AES-256-CBC 加密存储、资源可见性规则、越权返回 `NOT_FOUND` 而非 403），不夸大。另附更稳妥版与更强传播版各一个。

## 核准过的产品事实（后续可复用）

全部来自代码，非文档转述：

- **连接器 26 个**（`datasources/connectors/registry.py`）：数据库 8 / 消息 4 / API 2 / 文件 4 / SaaS 8；其中 `ldap`、`active_directory`、`dingtalk`、`wecom`、`feishu` 为 source-only
- **开放门面**（`open_api/catalog.py`）：能力目录分 application / data / messaging / identity 四类
- **10 个稳定错误码**（`open_api/errors.py`），含 `IDEMPOTENT_REPLAY` 返回 HTTP 200 这一反直觉设计
- **凭证可配项**（`open_api/models.py` `IntegrationClient`）：`scopes`、`ip_whitelist`、`rate_limit_per_minute`（默认 60）、`monthly_call_quota`、`monthly_row_quota`、`sandbox`、`callback_url`、`alert_email`、`alert_webhook_url`
- **10 项作用域**（`open_api/catalog.py` `DEFAULT_SCOPES`）
- **配额模型**（`ClientEntitlement`）：`max_jobs` / `max_seats` / `max_connectors` / `max_rows_monthly` / `max_api_calls_monthly`，**0 = 不限**
- **租户隔离规则**（`open_api/tenancy.py`）：`Q(created_by=oid) | Q(client_id=oid)`
- **映射转换规则**（`jobs/mapping.py` `VALID_TRANSFORMS`）：17 项 + snake_case 别名，`custom` 必须带 `params.expression`
- **双语言 SDK 方法名对齐**：`catalog` / `sdk` / `me` / `datasources` / `jobs` / `inspect` / `triggerJob` / `ingest`
- **5 套同步模板**（`org_sync/templates.py`）

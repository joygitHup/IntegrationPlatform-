## 追加：补齐真正的 PPTX 交付（用户反馈「PPT 啊 大哥」）

**问题**：上一轮交付的是 HTML 演示稿，但用户要的是能在 PowerPoint 里打开、能塞进自己模板、能走邮件转发的 **`.pptx` 文件**。HTML 不是替代品。

**交付物**：
- `.workbuddy/artifacts/产品介绍-集成中台.pptx` — 21 页 16:9 演示稿，与 HTML 版同内容同结构，**每页带讲者备注**
- `.workbuddy/scripts/build_ppt.py` — 可重跑的生成脚本（python-pptx）

**技术栈**：python-pptx 1.0.2，venv 位于 `C:/Users/lenovo/.workbuddy/binaries/python/envs/default`。运行需 `PYTHONUTF8=1`。

**踩过的坑（重要，下次直接规避）**：
1. 只设 `font.name` 只改到 `a:latin`，中文会回退主题字体 → 必须同时写 `a:ea` 与 `a:cs` 的 `typeface`
2. 卡片内纵向累加不能用估算常数，必须用 `size × 1.22 × line_spacing / 72` 算真实行高，否则正文会压住分隔线与价值行
3. 表格单元格 `tcPr` 子元素有 schema 顺序要求：`ln*` 必须在 `solidFill` 之前 → 用 `insert(0, ln)` 写入
4. Windows 上不适合用 COM 拉 PowerPoint 渲染做视觉校验（属 GUI 进程）；改用静态校验脚本判断越界与溢出即可
